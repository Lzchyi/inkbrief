## Circuit outline audit

All 23 active circuit IDs resolve to pinned GeoJSON geometry from
`bacinger/f1-circuits`; none uses the generic fallback. The mapping also keeps
cancelled Jeddah for historical/live-payload compatibility. The renderer uses
current production silhouettes, including MADRING, the post-2023 Marina Bay
layout, and the current Barcelona and Yas Marina layouts. Circuit lines are
never AI-generated.

The pinned dataset commit, checksum, licence, and per-ID mapping live in
`backend/kindle_brief/renderer/tracks.py` and `assets/tracks/`. Upstream track
names or length metadata are not used for the displayed event name or live
schedule.
